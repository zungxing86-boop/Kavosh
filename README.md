# مسیر من | My Journey

**شعار محصول:** «مسیر من؛ کشف توانایی‌ها، ساختن مهارت‌ها، طراحی آینده»

یک همراه دیجیتال آفلاین، امن و بازی‌وار برای نوجوانان ۱۲ تا ۱۴ سال که بر پایه اصول روان‌شناسی رشد، انگیزه درونی، اختیار و یادگیری مستقل طراحی شده است.

---

## ویژگی‌های اصلی پیاده‌سازی‌شده

- **۱۰۰٪ آفلاین و حفظ کامل حریم خصوصی**: تمام داده‌ها روی دستگاه (Room + DataStore + حافظه داخلی برنامه) ذخیره می‌شوند، بدون سرور خارجی، بدون تبلیغات و بدون مجوزهای غیرضروری.
- **دو زبانه کامل (فارسی RTL و انگلیسی LTR)** با فونت بومی `Vazirmatn` برای فارسی و `Plus Jakarta Sans` برای انگلیسی و تغییر پویا در لحظه.
- **سه حالت نمایش**: روشن، تیره و هماهنگ با سیستم با پالت اختصاصی (سرمه‌ای عمیق، فیروزه‌ای، نارنجی، طلایی و کرم روشن).
- **جریان ورود و ساخت قهرمان**: صفحه خوشامدگویی، شخصی‌سازی نام، آواتار، رنگ، نشان و تصویر گالری (با Android Photo Picker بدون نیاز به مجوز ذخیره‌سازی)، انتخاب از ۱۴ دسته‌بندی علاقه و تنظیم ترجیحات اختیاری.
- **چهار سرزمین و نقشه ماجراجویی قابل پیمایش**:
  1. سرزمین کشف خود (روزهای ۱ تا ۷)
  2. سرزمین یادگیری (روزهای ۸ تا ۱۴)
  3. سرزمین قدرت ذهن (روزهای ۱۵ تا ۲۲)
  4. سرزمین آینده‌سازان (روزهای ۲۳ تا ۳۰)
- **۳۰ مأموریت کامل دوزبانه** در `assets/missions/missions.json` همراه با داستان، هدف، ابزار، مراحل قابل تیک زدن با ذخیره خودکار، نسخه کوتاه برای روزهای پرمشغله، پرسش‌های بازتاب، بازخورد و ثبت علت توقف بدون هیچ‌گونه جریمه یا کسر امتیاز.
- **سیستم تجربه XP، سطوح و مهارت‌ها**:
  - شروع فعالیت (`+2 XP`)، ادامه مراحل (`+2 XP`)، ثبت نتیجه و آموخته (`+1 XP`) با سقف روزانه `5 XP` و جلوگیری تراکنشی از ثبت تکراری.
  - ۵ سطح پیشرفت (تازه‌وارد، جست‌وجوگر، کاوشگر، سازنده، استاد مسیر).
  - ۵ مهارت اصلی و ۱۲ دستاورد مبتنی بر کیفیت تجربه.
- **موتور پیشنهاد مأموریت آفلاین**: ارائه ۳ پیشنهاد متناسب (علاقه اصلی، مهارت کمتر تمرین‌شده، کشف تجربه جدید).
- **آزمایشگاه پروژه‌ها**: ساخت و مدیریت پروژه‌ها با مراحل، یادداشت‌ها، وضعیت‌ها، ضمائم فایل/تصویر از طریق Storage Access Framework و Photo Picker و کنترل کامل نوجوان برای اشتراک‌گذاری اختیاری با خانواده.
- **دفترچه خصوصی**: فضای امن با دسته‌بندی و جست‌وجو که **هیچ دسترسی خودکاری از سوی اتاق خانواده ندارد**.
- **همراه من**: ۶ ماژول راهنمای تعاملی آفلاین (هدف‌گذاری، حل مسئله، یادگیری، تمرکز، مدیریت پروژه، تفکر انتقادی) با امکان ذخیره مستقیم در دفترچه یا پروژه.
- **اتاق خانواده**: محافظت‌شده با رمز هش‌شده (`PBKDF2WithHmacSHA256` + Salt)، محدودیت ۵ تلاش ناموفق با قفل موقت ۵ دقیقه‌ای، بازیابی امن، نمایش صرفاً خلاصه پیشرفت و پروژه‌های هم‌رسانی‌شده و امکان ثبت پیام حمایتی.
- **پشتیبان‌گیری و بازیابی ZIP (SAF)**: خروجی ZIP شامل manifest معتبر، انتخاب صریح برای شامل کردن دفترچه، رمزگذاری اختیاری `AES-256-GCM` با مشتق‌سازی کلید `PBKDF2` و بازیابی اتمیک بدون تخریب داده‌های فعلی.

## راهنمای ساخت، اجرا و آزمون

### پیش‌نیازها
- Android Studio / JDK 17+ / Android SDK 36 (حداقل نسخه پشتیبانی‌شده روی دستگاه: Android 7.0 / 8.0+)

### دستورات ساخت و تست
```bash
# اجرای آزمون‌های واحد و Robolectric (موتورها، پایگاه داده، پشتیبان رمزنگاری‌شده و UI)
gradle :app:testDebugUnitTest

# ساخت نسخه Debug APK
gradle :app:assembleDebug
```
خروجی APK دیباگ در مسیر زیر ایجاد می‌شود:
`app/build/outputs/apk/debug/app-debug.apk`

## راهنمای توسعه محتوای مأموریت‌ها و سرزمین‌ها
تمام محتوای ثابت برنامه در پوشه `app/src/main/assets/` قرار دارد:
- `missions/missions.json`: لیست ۳۰ مأموریت با تمام ۱۸ فیلد دوزبانه
- `territories/territories.json`: تعریف ۴ سرزمین
- `skills/skills.json`: ۵ مهارت اصلی و ۱۴ علاقه پیش‌فرض
- `achievements/achievements.json`: ۱۲ نشان و شرط دریافت آن‌ها
- `companion/companion_modules.json`: ماژول‌های راهنمای «همراه من»
